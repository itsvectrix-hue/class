# Tonexa Music Academy

React + Vite website for home music tuition enquiries.

## Academy details
- Name: Tonexa Music Academy
- Email: tonexa.music.acadmy@gmail.com
- Teaching model: Home tuition only
- Instruments: Keyboard, Guitar, Drums, Conga and Vocals
- Colours: Deep Navy Blue (#0A1F44), Rich Gold (#C9A227), Off White (#F9F9F9)

## Design
- Dark navy and gold editorial hero inspired by the approved reference.
- Responsive navigation and instrument showcase.
- Custom Tonexa house-and-music-note SVG logo.
- Hero still-life artwork: `public/tonexa-instruments.webp`.

## Interactions
The project includes 30 locally implemented React Bits-inspired patterns in `src/ReactBits.jsx`.

## Pages
- Home: instruments, home tuition details, FAQs and enquiry form.
- Terms of use: `/terms`
- Privacy policy: `/privacy`
- Custom 404: `404.html`

## Enquiries
The form opens an email draft addressed to the academy. It does not send automatically, book a lesson, or store enquiry details in a website database.

## Local development
```sh
npm install
npm run dev
```

## Build
```sh
npm run build
npm run preview
```
