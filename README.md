# Naveen's Musical Class

A bespoke, responsive website for Naveen's Musical Class, built with React and Vite.

## Art direction

- Warm paper: #F9F8F6
- Deep charcoal: #1A1A1A
- Olive accent: #4A5D4E
- Instrument Serif display typography with Inter body text
- Editorial split layouts, generous whitespace, and typographic hierarchy
- Original inline SVG instrument artwork; no generic stock-photo placeholders

## Experience

- Home, About, Lessons / Instruments, Timings & Fees, Gallery, Contact
- WhatsApp enquiry flow and one-tap calling: +91 90286 71906
- Enquiry form that opens a pre-filled WhatsApp message
- Responsive navigation, accessible form labels, reduced-motion support
- Course fees and schedules are not fabricated; visitors can request current details

## React Bits motion layer

The repository includes 32 locally implemented React Bits-inspired components and effects in src/components/ReactBits.jsx. The page intentionally uses a limited set (Split Text, Scroll Reveal, Magnet, Scroll Float and Circular Text) so motion supports the design instead of competing with it.

Reference library: https://reactbits.dev/
