# Tonexa Music Academy

A React and Vite website for music lessons arranged at students' homes.

## Academy details
- Name: Tonexa Music Academy
- Email: tonexa.music.acadmy@gmail.com
- Teaching model: Home tuition only
- Instruments: Keyboard, Guitar, Drums, Conga and Vocals
- Brand colours: Deep Navy Blue (#0A1F44), Rich Gold (#C9A227), Off White (#F9F9F9)

## React Bits inspired interactions
This build contains 30 lightweight, locally implemented interaction patterns inspired by the free React Bits catalogue. They are adapted to the academy's visual system and do not add another animation framework dependency.

1. SplitText
2. BlurText
3. TextType
4. RotatingText
5. CurvedLoop
6. VariableProximity
7. TextPressure
8. ShuffleText
9. TextScatter
10. ScrollReveal
11. FadeContent
12. AnimatedContent
13. ScrollFloat
14. CountUp
15. ScrollProgress
16. Magnet
17. ClickSpark
18. Ripple
19. GlareHover
20. TiltedCard
21. SpotlightCard
22. AnimatedList
23. StaggeredMenu
24. LogoLoop
25. Waveform
26. HoverPreview
27. Parallax
28. Accordion
29. CardSwap
30. ScrollVelocity

These are custom, lightweight implementations inspired by the React Bits project, rather than imported Pro components.

## Pages
- Home: lessons, home tuition details, FAQs and enquiry form.
- Terms of use: `/terms`
- Privacy policy: `/privacy`
- Custom missing page: `404.html`

## Enquiries
The form prepares an email draft addressed to the academy. It does not send the email automatically, book a lesson, or store enquiry details in a website database. Visitors review the message and choose whether to send it.

Lesson availability, travel arrangements, timings and fees must be confirmed directly with the academy.
